## Chạy lại

Từ `backend`:

```powershell
python -B -m pytest -q --tb=short
```

Test dịch vụ thật chỉ đọc, không tạo dữ liệu:

```powershell
$env:FLAMEE_TEST_LIVE_READONLY='1'
python -B -m pytest tests/test_live_readonly.py -q --tb=short
Remove-Item Env:FLAMEE_TEST_LIVE_READONLY
```

Sau khi migration hoàn tất, chạy lại live tests trước khi test các API ghi dữ liệu.
