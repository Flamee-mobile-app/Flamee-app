# OpenMoji mood assets

The PNG files in this directory are unmodified 72×72 color exports from
[OpenMoji](https://openmoji.org/) by the OpenMoji contributors.

License: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

Asset source:
`https://github.com/hfg-gmuend/openmoji/tree/master/color/72x72`

Unicode mapping used by Flamee:

- `happy.png` — U+1F604
- `loved.png` — U+1F970
- `hopeful.png` — U+1F929
- `calm.png` — U+1F60C
- `uncertain.png` — U+1F615
- `tired.png` — U+1F62B
- `sad.png` — U+1F622
- `overwhelmed.png` — U+1F92F
- `neutral.png` — U+1F610
